# Слот-игра 5x3

Игровой слот с 5 барабанами и 3 рядами символов, 15 выигрышными линиями, реализованный на Python (Flask) и React с анимациями на Pixi.js.

## Особенности

- 5x3 игровое поле
- 15 выигрышных линий
- Анимация вращения барабанов с помощью Pixi.js
- Подсветка выигрышных символов и линий
- Настраиваемые веса символов и выплаты через JSON-конфигурацию
- Функция тестирования RTP через 1000 спинов
- Детальная статистика по результатам тестов

## Структура проекта

```
slot-game/
├── backend/             # Серверная часть на Flask
│   ├── app.py           # Основной файл сервера
│   ├── config.json      # Конфигурация символов и выигрышных линий
│   └── requirements.txt # Зависимости бэкенда
└── frontend/            # Клиентская часть на React
    ├── public/          # Статические файлы
    └── src/             # Исходный код
        ├── api/         # API для взаимодействия с бэкендом
        ├── components/  # React-компоненты
        ├── game/        # Логика игры на Pixi.js
        └── types/       # TypeScript типы
```

## Запуск проекта

### Бэкенд

1. Перейдите в директорию бэкенда:
   ```
   cd backend
   ```

2. Установите зависимости:
   ```
   pip install -r requirements.txt
   ```

3. Запустите сервер:
   ```
   python app.py
   ```

Сервер будет доступен по адресу: http://localhost:5000

### Фронтенд

1. Перейдите в директорию фронтенда:
   ```
   cd frontend
   ```

2. Установите зависимости:
   ```
   npm install
   ```

3. Запустите приложение в режиме разработки:
   ```
   npm start
   ```

Приложение будет доступно по адресу: http://localhost:3000

## Настройка RTP и выигрышных комбинаций

Настройка весов символов, выплат и выигрышных линий производится в файле `backend/config.json`.

### Структура конфигурационного файла

```json
{
  "symbols": {
    "A": {"weight": 1, "payout": {"3": 5, "4": 10, "5": 20}},
    "B": {"weight": 2, "payout": {"3": 4, "4": 8, "5": 15}},
    "C": {"weight": 3, "payout": {"3": 3, "4": 6, "5": 10}},
    "D": {"weight": 4, "payout": {"3": 2, "4": 4, "5": 8}},
    "E": {"weight": 5, "payout": {"3": 1, "4": 2, "5": 5}}
  },
  "paylines": [
    [{"row": 1, "col": 0}, {"row": 1, "col": 1}, {"row": 1, "col": 2}, {"row": 1, "col": 3}, {"row": 1, "col": 4}],
    [{"row": 0, "col": 0}, {"row": 0, "col": 1}, {"row": 0, "col": 2}, {"row": 0, "col": 3}, {"row": 0, "col": 4}],
    [{"row": 2, "col": 0}, {"row": 2, "col": 1}, {"row": 2, "col": 2}, {"row": 2, "col": 3}, {"row": 2, "col": 4}],
    [{"row": 0, "col": 0}, {"row": 1, "col": 1}, {"row": 2, "col": 2}, {"row": 1, "col": 3}, {"row": 0, "col": 4}],
    [{"row": 2, "col": 0}, {"row": 1, "col": 1}, {"row": 0, "col": 2}, {"row": 1, "col": 3}, {"row": 2, "col": 4}]
  ],
  "rtp_target": 0.95
}
```

- `symbols`: Настройки символов
  - `weight`: Вес символа (вероятность выпадения)
  - `payout`: Выплаты за комбинации разной длины
- `paylines`: Конфигурация выигрышных линий
- `rtp_target`: Целевой показатель RTP (Return to Player)

## Тестирование RTP

Для тестирования RTP используйте кнопку "1000 спинов" в интерфейсе. После выполнения тестов будет отображена подробная статистика:

- Общая сумма ставок
- Общая сумма выигрышей
- Количество спинов
- Частота выигрышей
- Самый большой выигрыш
- Фактический RTP
- Частота выпадения каждого символа

## Технические детали

- Бэкенд: Flask (Python)
- Фронтенд: React с TypeScript
- Стили: Tailwind CSS (v2.2.19)
- Анимации: Pixi.js (v6.5.2)
- Взаимодействие с API: Axios

## Архитектурные особенности

- React отвечает только за UI и управление состоянием
- Pixi.js полностью изолирован от React и отвечает за рендеринг и анимацию слота
- Взаимодействие между React и Pixi.js происходит через прямые вызовы методов
- Бэкенд предоставляет API для генерации результатов спинов и управления балансом
